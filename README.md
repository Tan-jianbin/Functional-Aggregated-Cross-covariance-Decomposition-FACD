# Associating High-Dimensional Longitudinal Datasets through an Efficient Cross-Covariance Decomposition

This repository contains the data and code associated with the paper **"Associating High-Dimensional Longitudinal Datasets through an Efficient Cross-Covariance Decomposition"** by *Jianbin Tan* and *Pixu Shi*.

The code studies associations between two high-dimensional longitudinal datasets through cross-covariance decomposition, functional loadings, and feature selection. In addition to the main simulations and exercise-cohort analysis, the repository includes convergence and initialization diagnostics and a time-point subsampling sensitivity analysis.

## 1. Data

### Data Description

The real-data application uses blood samples from 36 participants who underwent a controlled exercise protocol following overnight fasting. The original dataset was obtained from [the Stanford multi-omics data portal](http://hmp2-data.stanford.edu/).

The repository contains source data, processed longitudinal datasets, and saved analysis results. Simulation data are generated by the R functions during execution; the saved simulation files contain results from those experiments.

### Data Files

| `Data/Lipid.rda` | Processed `Lipid` object. |

### Processed Data Structure

The three processed `.rda` files in ‘Data/’ contain lists created by `wrap.dat()` in `Function.R`:

- `dat[[j]][[i]]`: observations for feature `j` and participant `i`, with `time` and `val` columns.
- `n` and `p`: number of participants and features.
- `sub_label` and `feature_label`: participant and feature identifiers.
- `time_grid`, `time_min`, and `time_max`: observation-grid information.

Preprocessing centers and scales each feature. The processed `.rda` files can be used directly for the real-data analysis.

### Script Guide

| File | Purpose and relationship to other files |
| --- | --- |
| `Function.R` | Implements `wrap.dat()`, `data_gen()`, basis/covariance estimation, `FACD()`, `plot_FACD()`, and `simu_func()`, together with comparison-method routines. Shared by the main simulation and analysis scripts. |
| `LCCA_function.R` | Supplies LCCA routines used in simulation and real-data comparisons. |
| `Conduct_sim.R` | Runs the main simulation grid through `Simulation.R`, summarizes correlation and variable-selection errors, prints a LaTeX table, and plots variable-selection and loading errors. |
| `Simulation.R` | Runs 100 replications for a single setting using `snowfall`. Requires parameters supplied by `Conduct_sim.R`; it is not a standalone entry point. |
| `FACD_computation.R` | Examines iterative convergence and sensitivity to perturbations of the SVD initialization. Prints summaries and computing-environment information and saves a diagnostic figure. |
| `data_preprocess.Rmd` | Reads source measurements and metadata, constructs transformed multi-omics data, and saves the three processed longitudinal objects. |
| `Data_analysis.Rmd` | Fits protein–metabolite, protein–lipid, and metabolite–lipid associations; saves fitted objects, selected-feature tables, and application figures. |
| `Data_analysis_comp.R` | Implements six-fold comparison calculations for protein–metabolite data and plots score correlations from the three saved pairwise fits. |
| `Data_sensitivity_analysis.R` | Refits the first protein–metabolite FACD component after time-point subsampling and summarizes feature-selection stability and loading alignment. Requires the full-data protein–metabolite fit. |

### Reproducibility

#### Preprocessing

Run `data_preprocess.Rmd` to rebuild the processed data from `Data/Source_data/`.

Outputs:

- `Data/exercise_log10_multiomic.RDS`
- `Data/Protein.rda`
- `Data/Metabolomic.rda`
- `Data/Lipid.rda`

#### Main Simulation Study

Run `Conduct_sim.R` for the main simulation study described in Section 5 of the paper. It sources `Simulation.R` for every combination of sample size and dimension ratio.

| Parameter | Current default |
| --- | --- |
| Sample size `n` | 50, 100, 150 |
| Dimension ratio `p / n` | 0.5, 1, 1.5, with `p_X = p_Y` |
| Correlation `rho` | 0.8 |
| Number of generating components `comp` | 20 |
| Maximum number of observation times `time_num` | 8 |
| Number of important variables `p_ture` | 10 |
| Replications per setting | 100 |
| Parallel workers | 40, configured in `Simulation.R` |

The spelling `p_ture` follows the existing code. Results are saved as `Result/Result_<n>_<p_X>.rda`, each containing a `Result` object. The driver creates `Figure/CCA_var_sim.pdf` and `Figure/CCA_loading_sim.pdf` and prints a LaTeX-formatted correlation-error table.

#### Convergence and Initialization Analysis

Run `FACD_computation.R` to examine convergence and initialization stability. Defaults include:

- `n = 150` and dimension ratios `0.5, 1, 1.5`.
- 100 replications per dimension setting and 20 perturbed initializations.
- Perturbation magnitude `0.1`, tuning parameters `lambda = c(0.01, 0.01)`, convergence tolerance `0.001`, and at most 200 iterations.
- 10 parallel workers and at most two attempts per simulation task, using an alternative seed for the retry.

The script prints diagnostic summaries, failed-task information, and computing-environment details. It saves `Figure/FACD_boxplot.pdf`; the current script does not persist the full diagnostic results to a separate data file.

#### Real Data Analysis

Run the chunks in `Data_analysis.Rmd` in order using the processed datasets. The analysis fits three pairs:

1. Protein and metabolite.
2. Protein and lipid.
3. Metabolite and lipid.

It saves the three fitted `Result` objects, feature tables, and figures listed below. Then run `Data_analysis_comp.R` for the method-comparison calculations and the combined score-correlation figure. The comparison script loads all three fitted objects for its final plot, so these files must already exist, either from the repository or from a new analysis run.

#### Time-Point Subsampling Sensitivity Analysis

Run `Data_sensitivity_analysis.R` after ensuring that `Result/fit_Protein_Metabolomic.rda` is available and corresponds to the processed data being analyzed.

The script studies the first protein–metabolite FACD component using 500 repetitions and up to 40 workers. For each participant, subsampling is applied with probability `0.1`. When selected, the procedure retains 80% of the common observation times, rounded down, subject to a minimum of three times when available. It uses the same retained times for both datasets.

Outputs include feature-selection probabilities and loading-alignment summaries in `Result/stability_summary_Protein_Metabolomic.csv`, together with `Figure/stability_Protein_Metabolomic.pdf`. The figure displays the top ten full-data features within each omic ranked by loading magnitude.
